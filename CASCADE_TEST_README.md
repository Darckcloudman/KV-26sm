# Cascade Spectrum Test - Тестирование каскадного графика

## 📋 Описание

Отдельный модуль для быстрого тестирования каскадного графика спектров ВЭУ.

Использует библиотеку **matplotlib** для построения 3D визуализации.

## 🚀 Быстрый запуск

### Вариант 1: BAT-файл на рабочем столе

Дважды кликните на:
```
C:\Users\79537\Desktop\CascadeSpectrumTest.bat
```

### Вариант 2: Из терминала

```bash
cd D:\Coding\pyton_pro
python test_cascade_standalone.py
```

## 📁 Данные

Тестовые данные должны находиться в:
```
D:\Coding\pyton_pro\test_data\cascade_extracted\
```

Формат имён файлов:
```
W1436 WTG37 SMP_YYYYMMDD_SENSOR_XX_HIGH_W.rd2
```

## ⚙️ Настройки

В файле `test_cascade_standalone.py` можно изменить:

```python
# Датчик (1-8)
sensor_id = 2

# Тип фильтра (FILTER, LOW, HIGH)
filter_type = "HIGH"

# Количество случайных спектров для отображения
max_spectra = 4
```

## 📊 Результат

После запуска:
1. Открывается окно с 3D графиком
2. Показывается каскад из 4 спектров разных дат
3. График сохраняется в `cascade_spectrum.png`

## 🎨 Визуализация

- **Ось X**: Частота (Гц)
- **Ось Y**: Записи (по датам)
- **Ось Z**: Амплитуда
- **Цвета**: Разные для каждой даты (радуга)

## 🐛 Если не работает

1. **Нет файлов**:
   ```
   [ERROR] Файлы не найдены: *SENSOR_02_HIGH_*.rd2
   ```
   → Распакуйте архивы в `test_data\cascade_extracted\`

2. **Нет matplotlib**:
   ```
   ModuleNotFoundError: No module named 'matplotlib'
   ```
   → Установите: `pip install matplotlib`

3. **Ошибка парсинга**:
   → Проверьте формат файлов .rd2 (должны быть от SMP12C)
