# Исправление ошибки TextItem

## 📅 Дата: 2025-01-28

---

## ❌ Описание ошибки

**Сообщение:**
```
TextItem.__init__() got an unexpected keyword argument 'font'
```

**Где возникала:**
- Файл: `kwf_prometheus/gui/charts/spectrum_chart.py`
- Класс: `BlinkingPeakMarker`
- Метод: `__init__()`

---

## 🔍 Причина

В `pyqtgraph.TextItem` параметр `font` **не принимается** как строковое значение в конструкторе. 

**Неправильно:**
```python
pg.TextItem(
    text=str(number),
    color='#FFFFFF',
    anchor=(0, 0),
    font='Arial 8'  # ❌ ОШИБКА: такой параметр не поддерживается
)
```

---

## ✅ Решение

Использовать метод `.setFont()` с объектом `QFont`:

**Правильно:**
```python
from PySide6.QtGui import QFont

text = pg.TextItem(
    text=str(number),
    color='#FFFFFF',
    anchor=(0, 0)
)
# Устанавливаем шрифт отдельно через метод
font = QFont('Arial', 8)  # Шрифт Arial, размер 8pt
text.setFont(font)  # ✅ Правильно
```
