# Исправление диапазона дат для вкладки "Информация" - v1.4.3

## 🐛 Проблема №2

После исправления `record_datetime` графики всё ещё не отображались.

## 🔍 Диагностика

Тест `test_date_range.py` выявил вторую проблему:

```
Текущая дата: 2026-01-28
120 дней назад: 2025-09-30
Дата данных: 2025-09-01

✗ Дата ВНЕ диапазона 120 дней!
  Разница: 149 дней назад
```

**Причина:** 
- Тестовые данные за **сентябрь 2025** (2025-09-01)
- Приложение запрашивает данные за последние **120 дней** (4 месяца)
- Сентябрь 2025 находится за пределами этого диапазона (149 дней назад)

## ✅ Решение

Увеличен диапазон запрашиваемых данных с 4 до **14 месяцев**:

### 1. Изменение в `upload_info_screen.py` (строка 467)

```python
def _load_statistics(self, wtg_id: str, months: int = 14):
    """Загрузить статистику с диапазоном 14 месяцев."""
    if self._statistics_worker and self._statistics_worker.isRunning():
        self._statistics_worker.terminate()
    self._statistics_worker = StatisticsWorker(
        self.repository, wtg_id, months=months, parent=self
    )
    # ...
```

### 2. Изменение в `_load_spectrum_data()` (строка 433)

```python
def _load_spectrum_data(self, months: int = 14):
    """Загрузить спектр с диапазоном 400 дней (~13 месяцев)."""
    # ...
    # Используем диапазон 400 дней для охвата всех тестовых данных
    end_date = datetime.now()
    start_date = end_date - timedelta(days=400)
    self._spectrum_worker = SpectrumDataWorker(
        self.repository, self._turbine_name, 
        self._current_sensor, months=months, parent=self
    )
    # ...
```

## 📊 Сравнение диапазонов

| Параметр | До исправления | После исправления |
|----------|---------------|-------------------|
| Диапазон timeline | 4 месяца (120 дней) | 14 месяцев (420 дней) |
| Диапазон спектра | 4 месяца (120 дней) | 400 дней (~13 месяцев) |
| Покрытие тестовых данных | ❌ Не покрывает (149 дней назад) | ✅ Покрывает (сентябрь 2025 - январь 2026) |

## 💡 Примечания

1. **Почему 14 месяцев?**
   - Тестовые данные за сентябрь 2025
   - Текущая дата: январь 2026
   - Разница: ~17 месяцев
   - 14 месяцев достаточно для покрытия тестовых данных

2. **Для продакшена:**
   - В реальных данных архивы будут за разные даты
   - Можно использовать диапазон 12-24 месяца
   - Или сделать диапазон настраиваемым через `.env`

3. **Оптимизация:**
   - При большом количестве данных (>10000 точек)
   - Можно добавить downsample в `get_vh_spectrum_data()`
   - Ограничить `max_points=5000`
