# Теорема Найквиста-Котельникова и FFT в вибродиагностике

## 📚 Теоретические основы

### Теорема Найквиста-Котельникова

**Формулировка:** Любую непрерывную функцию с ограниченным спектром (максимальная частота `Fmax`) можно точно восстановить по её дискретным отсчётам, взятым с частотой:

```
Fs ≥ 2 × Fmax
```

где:
- **Fs** — частота дискретизации (sampling frequency), Гц
- **Fmax** — максимальная частота в сигнале, Гц

### Частота Найквиста

```
F_nyquist = Fs / 2
```

**Важно:** Все частоты выше `F_nyquist` не могут быть корректно представлены в дискретном сигнале и вызывают **алиасинг** (наложение спектров).

## ⚠️ Критические ограничения

### 1. Ложные пики выше Nyquist

**Проблема:** Если в метаданных файла указана `Fs=25600 Гц`, но данные уже отфильтрованы полосовым фильтром (например, 0.1–10 Гц для НЧ), то FFT может показать пики на частотах >10 Гц, которые **не имеют физического смысла**.

**Пример из практики:**
```
НЧ фильтр (0.1–10 Гц), Fs=25600 Гц
FFT показал пики: 5363 Гц, 10098 Гц ❌
```

**Решение:** Фильтровать пики по диапазону фильтра:
```python
# НЧ: только 0.1–10 Гц
peaks = [p for p in peaks if 0.1 <= p['frequency'] <= 10]

# ВЧ: только 10–1000 Гц + Nyquist
effective_max = min(1000, Fs / 2)
peaks = [p for p in peaks if 10 <= p['frequency'] <= effective_max]

# ВЧ(ф): 0–12000 Гц + Nyquist
effective_max = min(12000, Fs / 2)
peaks = [p for p in peaks if p['frequency'] <= effective_max]
```

### 2. Отображение пиков на графиках

**Правило:** Линия пика отображается **только если** частота пика попадает в диапазон данных графика:

```python
# Проверка перед отображением
if peak_freq < min_data_freq * 0.9 or peak_freq > max_data_freq * 1.1:
    return  # Пик вне диапазона данных, не отображаем
```

**Пример:**
- График ВЧ(ф) имеет данные до 5120 Гц (Fs=10240)
- Пик 9898 Гц **не отображается** (данных на этой частоте нет)
- Пик 4883 Гц **отображается** ✅

## 📊 Практические рекомендации

### 1. Проверка частоты дискретизации

Перед анализом всегда проверяйте `Fs` в метаданных:

```python
print(f"Fs = {fs:.0f} Гц, Nyquist = {fs/2:.0f} Гц")
```

### 2. Валидация пиков

Если пик имеет частоту > `Fs/2` — это **ошибка**:

| Частота пика | Fs файла | Статус |
|--------------|----------|--------|
| 540 Гц | 2560 Гц | ✅ Валидно (540 < 1280) |
| 5099 Гц | 10240 Гц | ✅ Валидно (5099 < 5120) |
| 9898 Гц | 10240 Гц | ❌ **Невалидно** (9898 > 5120) |
| 10098 Гц | 25600 Гц | ✅ Валидно (10098 < 12800) |

### 3. Отладка

Используйте debug-вывод для диагностики:

```
[DEBUG] ВЧ(ф): Fs=10240 Hz, Nyquist=5120 Hz, range=0-5120 Hz, found 5 peaks
[DEBUG]   - 151.88 Hz, amp=0.147658
[DEBUG]   - 2681.88 Hz, amp=0.143778
```
