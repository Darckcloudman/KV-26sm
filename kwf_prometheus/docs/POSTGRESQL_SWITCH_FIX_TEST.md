# 🧪 Тестирование исправления переключения PostgreSQL

## ✅ Что было исправлено

**Проблема:** При активации режима PostgreSQL в настройках, приложение продолжало работать в файловом режиме.

**Решение:** 
- Обновлён метод `_on_settings_changed()` в `MainWindow`
- Добавлен метод `_update_all_screens()` для обновления репозиториев
- Динамическое создание `DataPersistenceService`
- Обновление всех экранов (HomeScreen, TrendsScreen, UploadInfoScreen)

---

## 📋 Шаги тестирования

### 1️⃣ Подготовка PostgreSQL

Убедитесь, что PostgreSQL запущен:
```bash
# Проверка статуса
pg_ctl status

# Или через службу Windows
Get-Service -Name postgresql*
```

### 2️⃣ Запуск приложения

```bash
cd D:\Coding\pyton_pro
python run_app.bat
```

### 3️⃣ Проверка текущего режима

**До изменений:**
- Посмотрите в статус-бар (нижняя панель)
- Должно быть: `Режим: Файловая система` (серая иконка 📁)

### 4️⃣ Включение режима PostgreSQL

1. **Меню** → **Настройки** (или Ctrl+,)
2. Перейдите на вкладку **"База данных"**
3. Включите переключатель **"Использовать базу данных"**
4. Проверьте параметры подключения:
   - Host: `localhost`
   - Port: `5432`
   - Database: `kv26sm`
   - User: `kv26sm_user`
5. Нажмите **"Сохранить"**

### 5️⃣ Проверка переключения

**После сохранения настроек:**

✅ **Ожидается:**
- Появится сообщение: `"Режим изменён на: PostgreSQL"`
- В статус-баре: `Режим: PostgreSQL (localhost)` (синяя иконка 🗄️)
- Иконка базы данных в статус-баре

❌ **Если не работает:**
- Сообщение об ошибке подключения
- Остаётся режим "Файловая система"

### 6️⃣ Проверка работы с БД

**Вкладка "Главная":**
- Должна отображаться статистика из БД
- Коэффициент готовности (если есть данные)

**Вкладка "Тренды":**
- Должны загружаться данные из БД
- Построение графиков по данным PostgreSQL

**Вкладка "Информация о загрузке":**
- Должны отображаться:
  - 3D спектр ВЧ(ф) из БД
  - Гистограмма записей за 4 месяца

### 7️⃣ Выключение режима PostgreSQL

1. **Меню** → **Настройки**
2. Выключите переключатель **"Использовать базу данных"**
3. Нажмите **"Сохранить"**

✅ **Ожидается:**
- Сообщение: `"Режим изменён на: Файловая система"`
- В статус-баре: `Режим: Файловая система` (серая иконка 📁)
- Приложение работает с локальными файлами

## 🔍 Диагностика проблем

### Ошибка подключения к PostgreSQL

**Сообщение:** `"Не удалось подключиться к PostgreSQL"`

**Решение:**
1. Проверьте, запущен ли PostgreSQL
2. Проверьте параметры подключения в настройках
3. Проверьте логи приложения

### Приложение не переключается

**Симптомы:** Режим остаётся "Файловая система" после сохранения

**Проверка логов:**
```python
# В файле лога ищите:
"Применение изменений настроек..."
"Репозиторий переключён: postgres"
"Все экраны обновлены"
```

### Трейсбэк в консоли

Если видите ошибку в консоли, проверьте:
- Версию `asyncpg`
- Параметры подключения к БД
- Логи `RepositorySwitcher`
