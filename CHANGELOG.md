## [1.4.2] - 2025-01-28

### 🎯 Основная функция

#### Интерактивное взаимодействие таблицы гармоник и графиков спектров

**Клик по строке таблицы** → **Показывает вертикальную линию пика на графике**

### ✨ Новые возможности

### Таблица гармоник (ТОП-10 пиков)
- **4 колонки**: Пик, Тип сигнала, Частота, Амплитуда+Зона
- **Глобальная нумерация** (1-10) для всех пиков из всех спектров
- **Интерактивность**: клик по строке показывает линию пика на соответствующем графике
- **Tooltip** при наведении на линию пика

### Графики спектров
- **Вертикальные линии** — жёлтые пунктирные при клике на таблицу
- **Автоматическое определение** графика для отображения пика (по диапазону частот)
- **Проверка диапазона данных** — пик показывается только если попадает в диапазон графика
- **Очистка линий** — при снятии выделения или выборе нового пика

### 🔧 Технические изменения

#### Анализ данных
- **Фильтрация пиков по диапазонам фильтров** (Nyquist theorem)
- **Улучшенный поиск пиков** для малых массивов (НЧ спектр <50 точек)
- **Проверка максимальной частоты данных** — предотвращение отображения пиков вне графика
- **Адаптивное масштабирование X** — график подстраивается под фактические данные

#### Компонент PeakPulseDot
- **Универсальный UI компонент** — пульсирующая красная точка
- **Анимация**: радиус 2px → 6px, прозрачность 100% → 0%
- **Бесконечный цикл** с easing InOutQuad
- **Tooltip** при наведении
- **Использование**: Home экран (схема турбины), Графики анализа

### 📝 Документация
- Добавлена документация по теореме Найквиста и FFT
- Документация tooltip для пиков
- Описание исправления отображения пиков

## [1.4.0] - 2025-06-01

### ✨ Новые возможности

#### 1. Единый сервис сохранения данных (DataPersistenceService)
- **Фасад над PostgresRepository** для всех точек входа
- **Асинхронный** — не блокирует GUI
- **Структурированный результат**: `{success, added, skipped, errors, wtg_id}`
- **Поддержка .zip и .rd2** файлов
- **Проверка processed_archives** — пропуск уже обработанных

#### 2. Автопарсинг иерархического хранилища (AutoScanService)
- **Структура**: `Корневой_каталог/YYYYMM/DD/*SMP_RWD_*.zip`
- **Периодическое сканирование** по таймеру (QTimer)
- **Рекурсивный обход** с ограничением глубины (max_depth=5)
- **Инкрементальная обработка**: проверка `file_size` + `mtime`
- **Настройки в .env**:
  - `AUTO_SCAN_ENABLED=true`
  - `AUTO_SCAN_INTERVAL_MINUTES=10`
  - `AUTO_SCAN_MAX_DEPTH=5`

#### 3. Таблица processed_archives
- **Отслеживание обработанных архивов**
- **Поля**: `file_path`, `file_size`, `file_mtime`, `turbine_wtg_id`, `records_added`, `records_skipped`, `processed_at`
- **Уникальный индекс** на `file_path`

#### 4. Поле sensor_serial в .rd2 файлах
- **Информационное поле** — порядковый номер записи за сутки
- **Не используется для дедупликации**
- **Заполняется из первого поля строки 1** .rd2 файла

### 🔧 Технические изменения

#### Модель Archive (обновлена)
- Добавлено поле `sensor_serial VARCHAR(50) NULL`
- **Не входит в уникальный ключ**

#### Уникальный ключ
```sql
UNIQUE(turbine_id, record_datetime, sensor_id, filter_type)
```

## [1.3.0] - 2025-01-27

### ✨ Новые возможности

#### 1. Data Access Layer (DAL)
- **Абстрактный репозиторий** `IVibrationRepository`
- **Две реализации**:
  - `FileSystemRepository` — режим v1.2 (файлы)
  - `PostgresRepository` — режим v1.3 (PostgreSQL)
- **Фабрика репозиториев** `get_repository()`

#### 2. PostgreSQL поддержка
- **Модели SQLAlchemy 2.0**: `Turbine`, `Archive`, `SensorData`, `AnalysisCache`
- **Асинхронный доступ** через `asyncpg`
- **Менеджер подключений** с пулом соединений

#### 3. Миграции
- **Alembic** для управления миграциями
- **Автоматическое создание таблиц** при первом запуске
- **Утилита migrate_archives.py** для импорта старых архивов

#### 4. Экспорт и отчёты
- **CSV экспорт** — 4 раздела (Метаданные, Временные ряды, Спектры, Результаты)
- **Excel экспорт** — 4 листа (openpyxl)
- **PDF-отчёт** — reportlab, 5 разделов, встроенные графики

#### 5. График трендов RMS
- **Новая вкладка "Тренды"**
- **Выбор турбины, датчика, типа фильтра**
- **Статистика**: мин, макс, среднее, количество записей

### 🔧 Технические улучшения

- **Асинхронность** — интеграция `asyncio` с `QThread`
- **Инъекция зависимостей** — репозиторий через конструктор
- **Кэширование** — спектры и анализ сохраняются в БД
- **Дедупликация** — SHA256 для архивов

## 📝 Формат версий

Проект использует семантическое версионирование: `MAJOR.MINOR.PATCH`

- **MAJOR** — несовместимые изменения API
- **MINOR** — новые функции (обратная совместимость)
- **PATCH** — исправления багов (обратная совместимость)
