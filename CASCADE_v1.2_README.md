# Cascade Spectrum Test v1.2 - Обновления

## ✅ Что нового в v1.2

### 1. Кнопки переключения датчиков (1-8)

![Кнопки](https://img.shields.io/badge/Датчик-1--8-green)

Добавлены 8 кнопок в верхней части графика:
- **Кнопка "1"**: Датчик 1
- **Кнопка "2"**: Датчик 2 (по умолчанию)
- ...
- **Кнопка "8"**: Датчик 8

**Как работает:**
- Кликните на кнопку с номером датчика
- График автоматически обновится
- Загрузятся 4 случайных спектра для выбранного датчика

### 2. Уменьшенная толщина линий

**Было:** `linewidth=2.0`  
**Стало:** `linewidth=1.2` (на 40% тоньше)

Это улучшает читаемость когда спектры накладываются друг на друга.

## 📊 Технические детали

### Обработчик кликов

```python
def _on_sensor_click(self, sensor_id: int):
    """При клике на кнопку датчика"""
    1. Закрывает текущий график
    2. Загружает данные для нового датчика
    3. Строит новый график с 4 случайными спектрами
```

### Цвета кнопок

- **Зелёная**: Текущий выбранный датчик
- **Серая**: Остальные датчики
- **При наведении**: Светло-зелёная подсветка

## 🚀 Использование

### Запуск

```bash
#BAT-файл на рабочем столе
CascadeSpectrumTest.bat

# Или из терминала
cd D:\Coding\pyton_pro
python test_cascade_standalone.py
```

### Переключение датчиков

1. Откроется график для **Датчика 2** (по умолчанию)
2. Кликните на кнопку **1**, **3**, **4** и т.д.
3. График обновится автоматически

### Примеры

**Датчик 1** (0.1-10 Гц, НЧ):
- Низкочастотная вибрация
- Обычно меньше пиков

**Датчик 2** (10-1000 Гц, ВЧ):
- Высокочастотная вибрация
- Хорошо видно гармоники

**Датчик 3-8** (разные позиции):
- Разные характеристики
- Можно сравнивать между собой
