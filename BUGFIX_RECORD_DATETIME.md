# Исправление вкладки "Информация о загрузке" - v1.4.3

## 🐛 Проблема

На вкладке "Информация о загрузке" не отображались графики:
- **3D спектр ВЧ(ф)** - "Нет данных для датчика 3"
- **Количество записей** - "Нет данных по записям"

## 🔍 Диагностика

Тест `test_upload_info.py` выявил проблему:

```
[OK] Найдено турбин: 1
  - WTG37 (архивов: 24)

[OK] Статистика:
  Архивов: 24
  Первая запись: None        ← ПРОБЛЕМА!
  Последняя запись: None     ← ПРОБЛЕМА!
  Критических: 0

[ERROR] Timeline пуст
[ERROR] Спектр ВЧ(ф) пуст
```

**Причина:** Поле `record_datetime` в таблице `archives` было `NULL` для всех записей.

## 📝 Корневая причина

В методе `PostgresRepository.load_archive()` дата записи извлекалась только из метаданных `.rd2` файла:

```python
record_datetime = self._parse_record_datetime(
    metadata.get('record_datetime', '')
)
```

Если в метаданных не было `record_datetime`, поле оставалось `None`.

## ✅ Решение

Добавлено резервное извлечение даты из имени файла:

### 1. Изменение в `load_archive()` (строка 171)

```python
# Парсим дату-время записи
record_datetime = self._parse_record_datetime(
    metadata.get('record_datetime', '')
)

# Если дата не найдена в метаданных, извлекаем из имени файла
if not record_datetime:
    record_datetime = self._parse_datetime_from_filename(archive_path)
    if record_datetime:
        logger.debug(
            "Дата извлечена из имени файла: %s",
            record_datetime
        )
```

### 2. Новый метод `_parse_datetime_from_filename()` (строка 467)

```python
def _parse_datetime_from_filename(self, file_path: Path) -> Optional[datetime]:
    """
    Извлечь дату-время из имени файла.
    
    Формат имени: SMP_YYYYMMDD_NNNNN_SENSOR_NN_FILTER_W.rd2
    Пример: SMP_20250901_38408_SENSOR_01_FILTER_W.rd2
    
    Args:
        file_path: Путь к файлу
        
    Returns:
        datetime или None
    """
    filename = file_path.name
    
    # Ищем паттерн SMP_YYYYMMDD
    import re
    match = re.search(r'SMP_(\d{8})_\d+', filename)
    
    if match:
        date_str = match.group(1)
        try:
            return datetime.strptime(date_str, "%Y%m%d")
        except ValueError:
            logger.warning(
                "Не удалось распарсить дату из имени файла: %s",
                filename
            )
    
    return None
```

## 📝 Примечания

1. **Формат имён файлов:**
   - `SMP_YYYYMMDD_NNNNN_SENSOR_NN_FILTER_W.rd2`
   - Дата извлекается из паттерна `SMP_20250901`

2. **Резервный механизм:**
   - Сначала пробуем метаданные `.rd2`
   - Если не удалось - из имени файла
   - Если не удалось - `None` (запись будет без даты)

3. **Обратная совместимость:**
   - Исправление не ломает существующий функционал
   - Работает для всех форматов имён с `SMP_YYYYMMDD`
