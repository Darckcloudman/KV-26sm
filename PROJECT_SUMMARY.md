# KWF Prometheus

## Текущая версия: 1.3

### Что нового в v1.3

#### Data Access Layer (DAL)
- **Абстрактный репозиторий** `IVibrationRepository` для работы с данными
- **Два режима работы**:
  - Файловая система (.zip/.rd2) - обратная совместимость с v1.2
  - PostgreSQL - для хранения больших объёмов данных
- **Кэширование результатов** анализа (спектры, RMS, зона)
- **Миграции Alembic** для управления схемой БД

#### Архитектурные изменения
- **Инъекция зависимостей** - репозиторий передаётся в конструкторы
- **Асинхронные операции** - `asyncio` + `QThread` без блокировки GUI
- **Модели SQLAlchemy 2.0** - Turbine, Archive, SensorData, AnalysisCache
- **Конфигурация .env** - Pydantic Settings для валидации

#### Структура v1.3
```
app/
├── .env                          ← Настройки (USE_DATABASE, DB_*)
├── migrate_archives.py           ← Утилита миграции архивов в БД
├── kwf_prometheus/
│   ├── dal/                      ← НОВЫЙ DAL слой
│   │   ├── config.py             ← Настройки из .env
│   │   ├── database.py           ← DatabaseManager
│   │   ├── models/               ← SQLAlchemy модели
│   │   ├── repositories/         ← Репозитории
│   │   └── alembic/              ← Миграции
│   ├── gui/
│   │   ├── main_window.py        ← Инъекция репозитория
│   │   └── home_screen.py        ← Работа с репозиторием
│   └── parsers/
│       └── rd2_parser.py         ← Без изменений
```

## Версия 1.2

### Архитектурные изменения

### Переход на стабильные фреймворки

| Компонент | Было | Стало | Причина |
|-----------|------|-------|---------|
| Графика | matplotlib | QPainter (PyQt5) | Стабильность, меньше зависимостей, быстрее рендер |
| Сборка EXE | PyInstaller | cx_Freeze | Совместимость с Python 3.14, надёжная упаковка |
| Шрифты UI | Geist Sans, Inter | Arial | Полная поддержка Unicode/кириллицы в Windows |
| Обработка данных | pandas | numpy + scipy | Избыточность pandas для задач FFT |
| GUI Framework | PyQt5 | PySide6 | Актуальная LTS-версия Qt, лицензия LGPL |

### Результат
- Уменьшено количество внешних зависимостей
- Увеличена стабильность работы GUI
- Исправлены проблемы с отображением кириллицы
- EXE-файл работает без дополнительных настроек

## Что нового в v1.2

### Экран Home (полная переработка)
- **Интерактивная схема турбины** (`shema.png`) с 8 кликабельными индикаторами датчиков
- **Плавно мигающие индикаторы** (`QVariantAnimation` + `QEasingCurve.InOutSine`):
  - `empty` — прозрачный кружок, чёрная рамка (датчик отсутствует в файле)
  - `ok` — зелёная пульсирующая рамка, прозрачный центр (все 3 сигнала загружены)
  - `partial` — жёлтая пульсирующая рамка, прозрачный центр (1–2 сигнала)
  - `none` — белый кружок, красная рамка, статичный (датчик в файле, но данных нет)
- **Таблица архивов** с кастомным скроллбаром (8 px, закруглённый, серый/белый)
- **Автосканирование** каталога `test_data` при старте
- **Выбор каталога архивов** через диалог

### Технические улучшения
- Переход с PyQt5 на **PySide6** (современная LTS, совместимость)
- Чёрная тема интерфейса (`#000000`)
- Координаты датчиков (`SENSOR_POSITIONS`) зафиксированы вручную под `shema.png`
