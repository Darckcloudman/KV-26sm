## 🎯 Основные изменения v1.4.3

### 1. Экран "Информация о загрузке" (Upload Info Screen)

**Новые возможности:**
- **3D спектр ВЧ(ф)** - визуализация спектра по осям: Дата (X), Гц (Y), Амплитуда (Z)
- **Статистика записей** - гистограмма количества архивов по дням (4 месяца)
- **Селектор датчиков** - 8 кнопок с цветовой индикацией статусов (🟢🟠🔴)
- **WTG без префикса** - отображение только "WTGxx" вместо "ВЭУ: WTGxx"
- **Параметры в строку** - все метаданные через "|"

**Технические детали:**
- Workers: `StatisticsWorker`, `SpectrumDataWorker`
- Методы БД: `get_records_timeline()`, `get_vh_spectrum_data()`
- Компоненты: `SensorSelector`, `Spectrum3DChart`, `RecordsChart`

### 2. Исправление индикатора режима

**Проблема:** Индикатор в статус-баре не обновлялся при переключении режима (PostgreSQL ↔ Файловый).

**Решение:**
- Исправлен порядок операций в `_on_settings_changed()`
- Добавлены проверки в `_update_mode_indicator()`
- Теперь индикатор корректно показывает:
  - 🔵 "Режим: PostgreSQL (localhost:5432)" - синий
  - ⚪ "Режим: Файловая система" - серый

### 3. Исправление file_hash

**Проблема:** `file_hash` не вычислялся (пустая строка), что вызывало konflikty при загрузке.

**Решение:**
- Включено вычисление SHA256 хэша в `load_archive()`
- Метод `_compute_file_hash()` теперь используется

### 4. Поддержка кириллицы в PDF (из предыдущих коммитов)

- Шрифт Arial для reportlab
- Информация о турбине в отчёте
- Топ-10 пиков вибрации
- Группировка датчиков (Редуктор/Генератор)

## 🐛 Известные проблемы

1. **Мало данных для 3D спектра** - в test_data только 1 день записей. Для полноценного 3D графика нужны данные за несколько месяцев.

2. **analysis_cache пуст** - кэш создаётся при первом анализе через GUI.

3. **Загрузка через скрипт не работает** - `load_test_data.py` требует доработки (проблема с типом возвращаемого значения).

**Решение:** Использовать загрузку через GUI.
