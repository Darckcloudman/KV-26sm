# Исправления для KWF Prometheus v1.4.3

## Проблема
1. **Нет графиков на вкладке "Информация о загрузке"** - показывает "Нет данных"
2. **Индикатор режима не обновляется** - постоянно показывает PostgreSQL, даже после переключения на файловый режим
3. **База данных не существовала** - нужно было создать БД vibrodiag

## Выполненные исправления

### 1. Создан файл .env
```bash
use_database=true
db_host=localhost
db_port=5432
db_name=vibrodiag
db_user=postgres
db_password=postgres
```

### 2. Исправлен метод `_on_settings_changed()` в `main_window.py`
**Проблема:** Индикатор режима обновлялся до переключения репозитория.

**Решение:** 
- Сначала переключаем репозиторий
- Обновляем все экраны
- **ПОТОМ** обновляем индикатор режима
- Дополнительно обновляем иконку статуса

```python
def _on_settings_changed(self):
    # ... переключение репозитория ...
    
    # СНАЧАЛА обновляем экраны
    self._update_all_screens()
    
    # ПОТОМ обновляем индикатор
    self._update_mode_indicator()
    self._update_status_icon('db' if self.repository_switcher.mode == 'postgres' else 'file')
```

### 3. Улучшен метод `_update_mode_indicator()` в `main_window.py`
**Проблема:** Метод мог вызвать ошибку если атрибуты ещё не созданы.

**Решение:**
- Добавлена проверка на существование `repository_switcher` и `mode_indicator`
- Получение режима напрямую из `repository_switcher.mode`
- Использование настроек по умолчанию если info не содержит данных

### 4. Создана база данных vibrodiag
```sql
CREATE DATABASE vibrodiag 
WITH OWNER = postgres 
ENCODING = 'UTF8' 
LC_COLLATE = 'Russian_Russia.1251' 
LC_CTYPE = 'Russian_Russia.1251';
```

### 5. Инициализированы таблицы БД
Запущен скрипт `init_db.py`, который создал 6 таблиц:
- `turbines` - турбины
- `archives` - архивы данных
- `sensor_data` - данные датчиков
- `sensors` - датчики
- `analysis_cache` - кэш анализа
- `processed_archives` - обработанные архивы

## Следующие шаги

### 1. Загрузить данные в БД
Запустить приложение и загрузить файлы через GUI:
```bash
python main.py
```

Или использовать автопарсинг:
- Файлы должны лежать в `./test_data`
- Автопарсинг включен в `.env`
- Интервал сканирования: 10 минут

### 2. Проверить загрузку статистики
После загрузки данных:
1. Перейти на вкладку "Информация"
2. Выбрать датчик (1-8)
3. Проверить отображение:
   - 3D спектр ВЧ(ф)
   - Количество записей (4 месяца)

### 3. Проверить переключение режима
1. Открыть Настройки
2. Переключить "Использовать PostgreSQL" (вкл/выкл)
3. Нажать "Применить"
4. Проверить статус-бар:
   - ✅ PostgreSQL: "Режим: PostgreSQL (localhost:5432)" - синий цвет
   - ✅ Файловый: "Режим: Файловая система" - серый цвет
