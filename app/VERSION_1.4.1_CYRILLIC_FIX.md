# Исправление кириллицы в PDF-отчётах (версия 1.4.1)

## Проблема

В версии 1.4.0 при экспорте PDF-отчётов вместо кириллического текста отображались **чёрные квадраты** (□□□□□).

## Причина

1. **reportlab** не регистрировал шрифты с поддержкой Unicode автоматически
2. **matplotlib** использовал шрифт по умолчанию без кириллицы
3. Отсутствовала явная регистрация TrueType шрифтов

## Решение

### 1. Регистрация шрифтов в reportlab

```python
from reportlab.pdfbase import pdfmetrics
from reportlab.pdfbase.ttfonts import TTFont

# Регистрируем Arial из Windows
pdfmetrics.registerFont(TTFont('Arial', r'C:\Windows\Fonts\arial.ttf'))
pdfmetrics.registerFont(TTFont('Arial-Bold', r'C:\Windows\Fonts\arialbd.ttf'))
```

### 2. Настройка matplotlib

```python
import matplotlib
matplotlib.rcParams['font.family'] = 'Arial'
matplotlib.rcParams['axes.unicode_minus'] = False
```

### 3. Автоматическая регистрация при запуске

Функция `_try_register_cyrillic_fonts()` автоматически определяет платформу и регистрирует доступные шрифты:

- **Windows**: Arial (встроен в систему)
- **macOS**: Arial (встроен в систему)
- **Linux**: DejaVuSans (fallback)

## Логи

При генерации PDF в логах должны быть сообщения:

```
=== НАЧАЛО РЕГИСТРАЦИИ ШРИФТОВ ===

Используемый шрифт: Arial (bold: Arial-Bold)
```

## Преимущества Arial

| Шрифт | Windows | Linux | macOS | Кириллица | Требуется установка |
|-------|---------|-------|-------|-----------|---------------------|
| **Arial** | ✅ Встроен | ⚠️ Через msttcorefonts | ✅ Встроен | ✅ Да | ❌ Нет (Windows/macOS) |
| DejaVu Sans | ❌ Нет | ⚠️ Нужно ставить | ⚠️ Нужно ставить | ✅ Да | ✅ Да |
| Helvetica | ⚠️ Нет | ✅ Есть | ✅ Есть | ❌ Нет | - |

## Установка на Linux

Для Linux систем потребуется установить шрифты Microsoft:

```bash
# Ubuntu/Debian
sudo apt-get install msttcorefonts

# CentOS/RHEL
sudo yum install msttcorefonts

# Arch Linux
yay -S ttf-ms-fonts
```

## Известные ограничения

1. **Emoji в логах**: Убраны из кода (проблема с кодировкой Windows console)
2. **Спецсимволы**: Длинные тире (—) могут отображаться как дефисы (-)
