# Changelog v1.4.3

## Дата: 04.06.2026

### Новые функции

1. **Улучшенный PDF-отчёт с полной поддержкой кириллицы**
   - Регистрация TrueType шрифтов Arial/Arial-Bold для PDF
   - Настройка matplotlib для использования Arial
   - Все текстовые элементы отчёта на русском языке

2. **Информация о турбине**
   - Номер ВЭУ в заголовке (например, "ВЭУ 40")
   - WTG ID в заголовке (например, "WTG40")
   - Дата записи по центру под заголовком
   - Детальная таблица параметров турбины

3. **Группировка датчиков**
   - Редуктор: Датчики 1-5
   - Генератор: Датчики 6-8
   - Наглядная таблица с цветовым кодированием зон

4. **Таблица "Топ-10 пиков вибрации"**
   - Для выбранного датчика
   - Частота, амплитуда, тип сигнала
   - Сортировка по амплитуде (по убыванию)

5. **Улучшенное заключение**
   - Показывает худший датчик
   - Перечисляет все датчики в той же зоне
   - Пример: "Датчик 3 показывает наихудшие значения в зоне C. Датчики 5, 7, 8 также в зоне C и требуют проверки"

6. **Детальная таблица параметров турбины**
   | Параметр | Значение | Единица |
   |----------|----------|---------|
   | ID турбины | W1436 | WTG40 |
   | Мощность | 2214.0 | кВт |
   | Частота вращения | 1118.0 | об/мин |
   | Скорость ветра | 0.0 | м/с |
   | Накопленная выработка | 22474158.0 | кВт·ч |

### Структура отчёта

**Страница 1:**
1. Заголовок с номером ВЭУ
2. Дата записи (по центру)
3. Параметры турбины
4. Состояние датчиков (с группировкой)
5. Топ-10 пиков вибрации

**Страница 2:**
4. Графики вибрации
5. Заключение

### Технические изменения

1. **pdf_generator.py**
   - Добавлен `_try_register_cyrillic_fonts()` для регистрации шрифтов
   - Поддержка платформ: Windows (Arial), macOS (Arial), Linux (DejaVuSans)
   - Улучшен `_create_turbine_table()` с добавлением WTG ID
   - Добавлен `_create_peaks_table()` для таблицы пиков
   - Улучшен `_generate_conclusion()` с перечислением всех проблемных датчиков
   - Добавлена группировка датчиков в `_create_sensors_table()`

2. **rd2_parser.py**
   - Добавлено возвращение `turbine_id`, `wtg_id`, `record_datetime` в `get_turbine_metrics()`
   - Улучшен парсинг метаданных из файлов .rd2

3. **pdf_report_thread.py**
   - Настройка `matplotlib.rcParams['font.family'] = 'Arial'`
