# SMP12C VibroDiag Analyzer — Итоговый отчёт

## 📋 Резюме

Проект воссоздания декompилированного приложения для анализа вибрационной диагностики ветротурбин системы SMP12C (Siemens Gamesa Renewable Energy).

### Исходные данные

| Параметр | Значение |
|----------|----------|
| **Источник** | Декремилированный EXE (70.44 MB, PyInstaller) |
| **Python версия** | 3.12 |
| **GUI фреймворк** | PyQt5 |
| **Визуализация** | matplotlib (backend_qt5agg) |
| **Библиотеки** | numpy, scipy, matplotlib, PyQt5 |
| **Формат данных** | .rd2, .rw2 (текстовый CSV-подобный) |

### Цель

Воссоздать функционал оригинального приложения в одном EXE файле с полным контролем над кодом.

## 🎯 Реализованная функциональность

### ✅ Парсинг .rd2 файлов

**Файл:** `smp12c_vibrodiag/parsers/rd2_parser.py`

- Извлечение метаданных из 5 строк заголовка
- Парсинг CSV-подобных данных вибрации
- Поддержка .rd2 и .rw2 форматов

**Методы:**
- `RD2Parser.parse()` — основная функция парсинга
- `process_rd2_file()` — полный алгоритм анализа

### ✅ Анализ вибраций

**Файл:** `smp12c_vibrodiag/parsers/rd2_parser.py` (класс VibrationAnalyzer)

- **Расчёт СКЗ (RMS)** — скользящее среднеквадратичное значение
  - Размер окна: 1024 samples
  - Перекрытие: 50%
  
- **FFT спектральный анализ** — быстрое преобразование Фурье
  - Убирает DC компоненту (0 Гц)
  - Возвращает частоты и амплитуды
  
- **Зонирование по ISO 10816**
  - Zone A: < 2.3 мм/с (Хорошо)
  - Zone B: 2.3 - 4.5 мм/с (Удовлетворительно)
  - Zone C: 4.5 - 7.8 мм/с (Неудовлетворительно)
  - Zone D: > 7.8 мм/с (Критично)
  
- **Поиск пиков в спектре** — топ-N максимальных амплитуд

### ✅ GUI на PyQt5

**Файл:** `smp12c_vibrodiag/gui/main_window.py`

**Функции:**
- Загрузка .rd2 файлов через диалог
- Загрузка ZIP-архивов с автоматической распаковкой
- Многовкладочный интерфейс (QTabWidget)
- Кнопки: Загрузить .RD2, Загрузить ZIP, Обработать, Сохранить
- Статусная строка с информацией

**Меню:**
- Файл → Открыть .RD2, Открыть ZIP, Сохранить, Выход
- Справка → О программе

### ✅ Визуализация

**Файл:** `smp12c_vibrodiag/gui/canvas.py`

- Интерактивные графики matplotlib в PyQt5
- Построение спектра с границами зон
- Подсветка зон цветом (зелёный/оранжевый/красный)
- Обработка клика мышью (координаты, значение)
- Сохранение в PNG

### ✅ Работа с файлами

**Файл:** `smp12c_vibrodiag/utils/file_handler.py`

- Распаковка ZIP архивов
- Рекурсивный поиск .rd2 файлов
- Сохранение графиков в PNG
- Временные директории с автоматической очисткой

```powershell

# Создать виртуальное окружение
python -m venv venv

# Активировать
.\venv\Scripts\Activate.ps1

```

### 2. Тестирование в режиме разработки

```powershell

```

### 3. Сборка EXE

```powershell

pyinstaller --onefile --windowed --name "SMP12C_VibroDiag" smp12c_vibrodiag/main.py

# Вариант 2: Использовать build.spec
pyinstaller --clean build.spec
```

## 🔍 Анализ формата .rd2

### Структура

```
<serial>, <timestamp>, <turbine>, <wtg>, <sensor>
Sampling Time, <val>, s, Sampling Frequency, <val>, Hz, Samples, <val>, sp, Duration, <val>, s
Generator Speed, <val>, RPM, Active Power, <val>, KW, Wind Speed, <val>, m/s, Cumulative Power, <val>, KWh
Device, 12C, Serial Number, <val>, MAC, <val>, IP, <val>, FW version, <val>
Number of Configuration, <val>, Configuration Table Version, <val>, Layout Version, <val>, Exception Applied, <val>, PLC IP Address, <val>
<index>, <timestamp>, <value>,
...
```

### Типы файлов

| Тип | Частота | Длительность | Отсчётов |
|-----|---------|--------------|----------|
| LOW_W | 64 Гц | 64 с | 4096 |
| HIGH_W | ~5120 Гц | ~1 с | 5120 |
