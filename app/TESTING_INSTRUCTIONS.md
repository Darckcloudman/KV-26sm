## Как тестировать

### Шаг 1: Запуск приложения

```powershell
cd D:\Сoding\pyton_pro\app
python -m kwf_prometheus.main
```

> **PowerShell:** При ошибке `PSSecurityException` используйте `powershell.exe -ExecutionPolicy Bypass -File .\install_and_run.ps1`

Или запустите скомпилированный `KWF_Prometheus.exe`.

### Шаг 2: Загрузка тестовых данных

**Вариант A: ZIP-архив**

1. Нажмите **«Загрузить ZIP»**
2. Выберите файл: `test_data/WTG6/WTG06_20231015_120000.zip` (если есть)
3. Либо используйте любой `.zip` с `.rd2` файлами внутри

**Вариант B: Отдельные файлы**

1. Нажмите **«Загрузить .RD2»**
2. Выберите несколько файлов из `test_data/`:
   - `W1436 WTG37 SMP_20250901_38408_SENSOR_01_LOW_W.rd2`
   - `W1436 WTG37 SMP_20250901_38408_SENSOR_02_LOW_W.rd2`
   - и т.д.

### Шаг 3: Экран «Информация о загрузке»

После загрузки файлов автоматически откроется экран информации.

**Проверьте:**

| Элемент | Ожидаемое поведение |
|---------|-------------------|
| Название ВЭУ | Извлекается из имени файла (например, `WTG06`, `WTG37`) |
| Список датчиков | 8 строк с `[+]` (загружен) или `[-]` (отсутствует) |
| Счётчик | «Загружено: X из 8. Отсутствуют датчики: Y, Z» |
| Кнопка [>] Обработать | Активна если X > 0 |
| Кнопка <- Назад | Возвращает на приветственную страницу |

**Описание датчиков:**

```
[1] Главный вал радиальный
[2] Редуктор передняя нижняя часть радиальный
[3] Редуктор средняя часть радиальный
[4] Редуктор задняя часть радиальный
[5] Генератор передняя часть радиальный
[6] Генератор задняя часть радиальный
[7] Лопасть 1 корень
[8] Лопасть 2 корень
```

### Шаг 4: Экран «Сырые данные»

Нажмите **[>] Обработать** на экране информации.

**Проверьте:**

| Элемент | Ожидаемое поведение |
|---------|-------------------|
| Сетка 2×4 | 8 панелей для датчиков |
| Заголовок панели | Номер и описание датчика |
| График | Временной ряд виброускорения (м/с²) |
| Нет данных | Серый фон с надписью для отсутствующих датчиков |
| Кнопка <- Назад | Возвращает к экрану информации |

### Шаг 5: Навигация

- **<- Назад к информации** -- возврат к экрану информации
- **<- Назад к выбору** -- возврат к приветственной странице
- **Home** вкладка -- главная страница приложения

## Возможные проблемы

### Проблема: Не извлекается имя ВЭУ

**Причина:** Имя файла не содержит паттерн `WTGxx` или `ВЭУxx`

**Решение:** Переименуйте файл в `WTG06_test.zip` или используйте метаданные из файла

### Проблема: Не определяется номер датчика

**Причина:** Имя файла не содержит `SENSOR_XX` или `XX`

**Решение:** Используйте файлы с именами типа `SENSOR_01_LOW_W.rd2`

### Проблема: Графики не отображаются

**Причина:** Нет данных о временном ряде в файле

**Решение:** Проверьте формат `.rd2` файла -- должен содержать временные метки
