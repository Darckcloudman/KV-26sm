# Интерактивное взаимодействие таблицы гармоник и графиков

## Обзор

В версии v1.4.1 добавлена интерактивная связь между таблицей гармоник (ТОП-10 пиков) и графиками спектров на экране **Анализ данных**.

## Возможности

### 1. Клик по таблице гармоник

При клике на строку таблицы гармоник:
- На соответствующем графике спектра появляется **вертикальная пунктирная линия** жёлтого цвета (`#FFD600`)
- Над линией отображается **информационная метка** с данными:
  - Частота пика (Гц)
  - Амплитуда (м/с² или мм/с)
  - Зона ISO 10816 (A/B/C/D)

### 2. Автоматическое определение графика

Система автоматически определяет, на каком графике отображать маркер:
- **НЧ** → график ускорения (0.1-10 Гц, м/с²)
- **ВЧ** → график скорости (10-1000 Гц, мм/с)
- **ВЧ(ф)** → график высокочастотного ускорения (0-12 кГц, м/с²)

### 3. Очистка маркеров

Маркеры автоматически очищаются при:
- Переключении на другой датчик
- Загрузке нового файла
- Клике на другую строку таблицы (старый маркер заменяется новым)

## Техническая реализация

### Изменённые файлы

#### `kwf_prometheus/gui/analysis_data_screen.py`

**Новые поля:**
```python
self._all_peaks = []       # Данные пиков для взаимодействия
self._peak_markers = []    # Маркеры пиков на графиках
```

**Новые методы:**
- `_on_harmonics_row_selected(row, column)` — обработчик клика по таблице
- `_add_peak_marker(chart, frequency, amplitude, unit, zone)` — добавление маркера на график
- `_clear_peak_markers()` — очистка всех маркеров

**Обновлённые методы:**
- `_update_harmonics_table()` — сохранение пиков в `_all_peaks`
- `_update_spectrums()` — очистка маркеров перед обновлением
- `_select_sensor()` — очистка маркеров при смене датчика

#### `kwf_prometheus/gui/charts/spectrum_chart.py`

**Новые импорты:**
```python
from pyqtgraph import InfiniteLine, TextItem
```

**Новое поле:**
```python
self._peak_markers = []  # Маркеры пиков (линии и текст)
```

**Новые методы:**
- `add_peak_marker(frequency, amplitude, label)` — добавить маркер пика
- `clear_peak_markers()` — очистить маркеры пиков

**Обновлённые методы:**
- `clear()` — теперь также очищает маркеры пиков

## Визуальный стиль

| Элемент | Стиль |
|---------|-------|
| Вертикальная линия | Пунктирная, жёлтая (`#FFD600`), толщина 2px |
| Текст метки | Белый на тёмно-сером фоне (`#333333`) |
| Расположение текста | В верхней части графика (95% высоты) |

## Пример использования

1. Загрузите архив `.zip` или файл `.rd2` через главный экран
2. Перейдите на вкладку **Анализ данных**
3. Выберите датчик кликом по индикатору или таблице
4. Кликните на строку в таблице **Таблица гармоник (ТОП-10 пиков)**
5. На соответствующем графике спектра появится маркер с информацией о пике

## Известные ограничения

- Маркеры не сохраняются при переключении между вкладками
- При изменении масштаба графика текст метки может перекрываться с другими элементами
- Одновременно отображается только один маркер (последний выбранный)
