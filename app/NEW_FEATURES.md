# Новые функции SMP12C VibroDiag Analyzer

## Обзор

Добавлены два новых экрана для улучшения диагностической прозрачности и интерактивности приложения.

---

## 1. Экран «Информация о загрузке»

**Появляется сразу после выбора файлов** (ZIP-архив или отдельные .rd2 файлы).

### Отображаемая информация

| Поле | Описание | Пример |
|------|----------|--------|
| **ВЭУ** | Название ветротурбины (извлекается из имени файла) | `WTG35` |
| **Скорость генератора** | Скорость вращения генератора | `1123 RPM` |
| **Активная мощность** | Производимая мощность турбины | `2334 KW` |
| **Длина записи** | Длительность записи вибросигнала | `64 s` |
| **Номер записи** | Первые 5 цифр идентификатора записи | `38408` |
| **Дата/время** | Момент записи данных | `01/09/2025 23:45:29` |

### Проверка полноты данных

Архив проверяется на наличие **трёх файлов** для каждого датчика:
- `SENSOR_XX_FILTER_W.rd2` -- фильтрованный сигнал
- `SENSOR_XX_HIGH_W.rd2` -- высокий диапазон
- `SENSOR_XX_LOW_W.rd2` -- низкий диапазон

**Индикаторы статуса:**
- `[OK]` -- все 3 файла присутствуют для датчика
- `[~] FILTER, HIGH` -- неполный набор (показывает какие файлы отсутствуют)
- `[-]` -- датчик не загружен

### Счётчик датчиков

| Состояние | Текст | Цвет |
|-----------|-------|------|
| Все 8 датчиков полностью | `[+] Все датчики загружены полностью (по 3 файла каждый)` | Зелёный |
| Все 8 датчиков, но неполные | `[!] Все 8 датчиков загружены, но N имеют неполный набор файлов` | Оранжевый |
| Недостаточно датчиков | `Загружено: X из 8. Отсутствуют датчики: Y, Z` | Оранжевый |

### Кнопки

| Кнопка | Действие |
|--------|----------|
| `<- Назад к выбору` | Возврат к экрану приветствия |
| `[>] Обработать` | Переход к экрану сырых данных (активна если загружен хотя бы 1 датчик) |

---

## 2. Экран «Сырые данные»

**Открывается после нажатия «Обработать»** на экране информации.

### Макет

- **Сетка 2×4** (2 колонки × 4 строки) -- 8 панелей для датчиков
- Каждая панель содержит:
  - Заголовок с номером и описанием датчика
  - График временного ряда виброускорения (м/с²)
  - Серый фон с надписью «Нет данных» для отсутствующих датчиков

### Описание датчиков

| № | Описание |
|---|----------|
| 1 | Главный вал радиальный |
| 2 | Редуктор передняя нижняя часть радиальный |
| 3 | Редуктор средняя часть радиальный |
| 4 | Редуктор задняя часть радиальный |
| 5 | Площадь выходного вала редуктора |
| 6 | Подшипник генератора DE (осевой) |
| 7 | Подшипник генератора DE (радиальный) |
| 8 | Подшипник генератора NDE (радиальный) |

### Технические детали

- **Децимация:** Для сигналов >10000 точек отображается подмножество данных для производительности
- **Независимое масштабирование:** Каждый график имеет авто-масштаб по Y
- **Синхронизация:** Ось X (время) независима для каждого датчика

### Кнопки

| Кнопка | Действие |
|--------|----------|
| `<- Назад к информации` | Возврат к экрану информации о загрузке |

## Обновления парсера

### Изменения в `rd2_parser.py`

| Поле | Формат | Описание |
|------|--------|----------|
| `record_number` | строка (первые 5 цифр) | Идентификатор записи |
| `record_datetime` | `DD/MM/YYYY HH:MM:SS` | Дата и время записи |
| `generator_speed` | `XXXX RPM` | Скорость генератора |
| `active_power` | `XXXX KW` | Активная мощность |
| `record_length` | `XX s` | Длина записи в секундах |

### Исправления

- **Парсинг данных:** Убрана ошибка с trailing запятой в строках данных (`0, 0, 0,` → `0, 0, 0`)
- **Форматирование метаданных:** Добавлены единицы измерения (RPM, KW, s)

## Дизайн

### Цветовая схема

| Элемент | Цвет |
|---------|------|
| Фон | `#000000` (чёрный) |
| Кнопки | `#ff69b4` (розовый неон) |
| Текст | `#e0e0e0` (светло-серый) |
| Границы | `#333333` (тёмно-серый) |
| Успех | `#00ff00` (зелёный) |
| Предупреждение | `#ffa500` (оранжевый) |
| Ошибка | `#ff0000` (красный) |

### Монохромные символы

Все эмодзи заменены на монохромные символы:
- `[+]` -- загружено/успех
- `[-]` -- отсутствует/ошибка
- `[OK]` -- полностью загружено
- `[~]` -- неполный набор
- `[>]` -- вперёд/обработать
- `<-` -- назад

## Тестирование

### Тестовые данные

```
test_data/zip/
├── W1436 WTG35 SMP_20250901_33680_W.zip  (24 файла, 8 датчиков × 3 типа)
├── W1436 WTG38 SMP_20250901_35180_W.zip
├── W1436 WTG40 SMP_20250901_40823_W.zip
├── W1436 WTG5 SMP_20250901_37055_W.zip
└── W1436 WTG56 SMP_20250901_32639_W.zip
```

### Инструкция

1. Запустите `SMP12C_VibroDiag.exe`
2. Нажмите **«Загрузить ZIP»**
3. Выберите архив из `test_data/zip/`
4. Проверьте экран **Информация**:
   - Имя ВЭУ (например, `WTG35`)
   - Параметры записи (скорость, мощность, длина, номер, дата)
   - Статусы датчиков `[OK]` / `[~]` / `[-]`
5. Нажмите **`[>] Обработать`**
6. Проверьте экран **Сырые данные**:
   - 8 графиков в сетке 2×4
   - Правильные описания датчиков
   - Кнопка `<- Назад к информации`
